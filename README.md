# Aleia — Privacy Policy

Aquest repo allotja la política de privacitat de l'app Aleia a
`https://KaidevLabs.github.io/aleia-privacitat/`.

L'HTML publicat és `index.html` a la branca `gh-pages`. S'actualitza
automàticament quan es fa push a `main` (veure `.github/workflows/deploy.yml`)
o manualment seguint `docs/play-store-listing.md` del repo principal
(KaidevLabs/photos-share-app).
